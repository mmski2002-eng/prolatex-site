# Витрина Про-Латекс (Next.js)

Это часть проекта, которая отдаёт страницы сайта посетителям. Полное описание проекта, установка с нуля и порядок обновления сервера — в [README.md](../README.md) в корне репозитория.

## Запуск

```bash
npm ci        # один раз после скачивания проекта
npm run dev   # http://localhost:3000
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | режим разработки, правки видны сразу |
| `npm run build` | сборка для сервера (самодостаточная, `output: "standalone"`) |
| `npm start` | запуск собранной версии локально |
| `npm run lint` | проверка кода |

## Где что лежит

- `src/app/` — страницы; имя папки совпадает с адресом страницы
- `src/components/` — блоки: шапка, подвал, карточки моделей, галерея, формы
- `src/data/` — данные сайта (копия `data/*.json` из корня репозитория)
- `src/lib/` — получение данных, SEO-разметка, вспомогательные функции
- `public/` — картинки, видео, шрифты

Данные берутся из WordPress, а если он недоступен — из `src/data/*.json`. Сайт полноценно работает без запущенного WordPress.
